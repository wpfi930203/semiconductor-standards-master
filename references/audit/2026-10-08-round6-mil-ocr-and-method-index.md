## 2. ★ 独立交叉校验：99% 重合

GJB 548 源自 MIL-STD-883，两者**方法号同源**。这给了一个天然的独立校验：

| 标准 | 与 883 方法号重合 | 仅本标准有 |
|---|---|---|
| `GJB-548B` | **74/75 = 99%** | `2023` |
| `GJB-548C` | **73/74 = 99%** | `2023` |

**这个校验的价值在于它不是自证**：两套标准来自不同的扫描件、不同的语种
（中文 vs 英文）、不同的目录版式，却收敛到同一组方法号。
这同时说明**两侧的 OCR 与解析都没有系统性错位**。

它也直接暴露了一个缺陷：最初一致率只有 95%，差在 `1011/1014/1018` 等号上
（见 §3.1）。

## 3. 本轮修掉的四个缺陷

### 3.1 数字内空格导致漏项（影响最大）

OCR 把 `1011` 读成 `101 1`，于是 `MRegex` 匹配不上，整条丢失。

实测样本（883K 目录页）：`101 1 ． 9` → 实为 `1011.9`。

修法：`squeeze_digits()`，去掉数字↔数字之间的空格（不动其他空格）。

**效果**：883K 方法号 **100 → 105**；交叉一致率 **95% → 99%**。

### 3.2 正文污染标题

初版解析器扫**全文**，于是正文里的句子被当成标题：

```
1003 → "的试验条件 A 进行绝缘电阻测试，或在 25 ℃ 下进行"     ← 正文句子
1005 → "件 F 的加速温度 / 时间试验条件，则该加速温度／时间试验条件应该"
```

修法：为每份标准定义**目录页范围**（883K p5-7、883F p4-7、548B p2-4、548C p1-3），
只在目录页内解析。

### 3.3 中文空格（Windows OCR 特性）

Windows OCR 会在汉字间插空格：`微 电 子 器 件 试 验 方 法`。

修法：`collapse_cjk_spaces()` —— 只折叠 **CJK↔CJK** 之间的空格，
保留 CJK↔拉丁/数字之间的空格（那是有意义的词边界）。

### 3.4 GJB-548C 文件一致性

`GJB-548C.txt` 里前 16 页是**旧脚本**（无 CJK 折叠）产的，
17-460 页是**新脚本**追加的 —— 同一文件里两种格式，还有重复块。

根因：我上一轮重置了 `GJB-548B` 但**忘了重置 `GJB-548C`**，
它的 `done_pages` 已有 1-16，于是全量跑时跳过并追加。

修法：重 OCR 1-16 页 → 按页序与旧页块合并 → 460 页整洁文件。

> 教训：**批量任务里只重置了一个对象，另一个就被漏掉了。**
> 这类错误不会报错，只会让数据静默地不一致 —— 是靠「同一页出现两次、格式还不同」这个
> 表象反查出来的。

## 4. 一个被否决的做法（留档）

GJB-548C 的**目录 I 页在扫描件里确实缺失**（p1 是封面、p2 直接跳到 `方法 1031`），
所以缺 `1001~1030`。

我先试了**从正文节标题补齐**（匹配 `方法 NNNN 标题` 同一行）。

**结果不可用**：正文里有大量交叉引用，产出的「标题」全是正文句子：

```
1005 → "方法 1008 、方法 10 巧、方法 5004 和方法 500"   ← 交叉引用句
1010 → "中试验条件 Ce 对 B 级器件可采用方法 10H 热冲击，但至"
2001 → "而不使用方法 200L1 。"
```

**已回退。** 改为：**同源标准参考** —— 用 `GJB-548B` 的目录补齐，
并逐条标注 `source: "同源标准参考"` +
`source_detail: "据 GJB-548B 目录（GJB-548C 目录相应页在扫描件中缺失）；
**GJB-548C 可能已修订该标题，不得直接引用**"`。

同时给出**缺口声明**（按系列内检测号段不连续），并明确写：
> 这可能是标准本身跳号，也可能是 OCR 漏识——**本清单不判断是哪种**。

> 这是本轮最有价值的一条纪律：**补齐可以，但不能让补齐结果冒充原标准内容。**
> 与其给一个看起来完整的表，不如给一个带来源标记和缺口声明的表。

## 5. 三种来源标记

| 标记 | 含义 | 可信度 |
|---|---|---|
| `目录页` | 该标准自己的目录页 OCR | 标题可能因读序错位，**须核对原页** |
| `同源标准参考` | 本标准目录页在扫描件中缺失，借用同源标准目录 | **可能已被修订，不得直接引用** |
| `OCR归一`（号带 `*`） | 号中含 OCR 混淆字符（`O/l/L/巧/&`），已按规则归一 | 号可信，建议核对 |

**归一规则**（数字位上的字符混淆，实测样本）：

| OCR 读到 | 实为 | 语境 |
|---|---|---|
| `101L1` / `201L1` | `1011` / `2011` | `L` → `1` |
| `101 & 1` | `1018.1` | `&` → `8` |
| `30 巧` | `3015` | `巧` → `15` |
| `201 &` | `2018` | `&` → `8` |
| `5010 ， 3` | `5010.3` | 全角逗号 |
