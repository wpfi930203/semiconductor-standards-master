## 1. 行业心智模型（Mental Models）

> 筛选标准：跨场景复现（≥2 处来源）+ 生成力 + 排他性。三重通过者入选。

### MM-1｜标准是「方法库」，资格标准是「裁判」——两者必须分离

**一句话**：JEDEC JESD22 是方法库（规定"怎么做"），JESD47 / JESD94 / AQG 324 / 客户 TS 才是裁判（规定"做多少、判什么"）。

**证据**：
- **一手**：JESD22-A104F.01 §5 原文明确把循环次数交给 "JESD47 or as agreed between the supplier and the customer"（`03-workflows.md` §0-1）
- **一手**：AQG 324 的引用表锁定方法编号后，QL-xx 表才给具体条件（`04-canon.md`）
- **反例佐证**：业内普遍存在的"照抄 A104 条件表"错误，正源于把方法库当裁判（`03-workflows.md` §3）

**应用方式**：拿到任何试验需求，先问"这是要我选方法，还是要定判定？"—— 前者查 JESD22，后者查资格标准。

**局限**：板级/互连场景（JEP150、IPC-9701）的方法与资格耦合较紧，分离不完全。

### MM-2｜零失效数据只能给「失效率上界」，永远不能给「寿命点估计」

**一句话**：n 件零失效 → 只能算 R_L（上界），不能算 MTTF；要证明 10ppm/90% 需约 23 万样本，数学上不可行。

**证据**：
- **数学**：卡方零失效上界 `R_L = 1 − χ²(1−CL)/2S`，其中 `S = Σ(n_i × t_i)` 累积应力小时数（`02-tools.md`、`03-workflows.md` §1.5）
- **实测**：用户 HV-H3TRB 三档数据 S = 74×168 + 23×1000 + 6×1500 = **44,432 pcs·h** → 这是上界的基础量，不是寿命
- **一手**：IEC 60749-34:2025 与 AQG 324 均从 test-to-pass 转向 test-to-fail（`02-tools.md`）

**应用方式**：报告零失效结果时，必须写「在 S=44,432 pcs·h、CL=90% 下，R_L = X ppm（95% 置信）」，**不得写"预计寿命 > Y 年"**。

**局限**：若失效为截尾（censored）数据，可用 Weibull 拟合提高效率；但真零失效无解。

### MM-3｜标准未覆盖是常态，且标准自己授权你偏离

**一句话**："标准没覆盖"不是标准体系的漏洞，而是 JESD47 明确列出的合法偏离情形。

**证据**：
- **一手**：JESD47 Scope 原文列出 4 类必须偏离标准条件的情形（`03-workflows.md` §0-8）
- **一手**：AQG 324 要求"若某项试验不适用于特定设计，供应商必须向客户说明不适用的理由"（`03-workflows.md` §3.1 STEP 1）
- **用户场景印证**：双焊片 + 高温密封剂工艺无标准直接覆盖，属此类

**应用方式**：偏离时必须留三样东西：① 物理依据 ② 等效性论证 ③ 客户确认记录。

**局限**：客户 TS 优先于通用标准，取严原则下"偏离标准"常变成"偏离客户"。

### MM-4｜功率模块的验证逻辑是「双轨制」：焊点疲劳与键合退化机理不同

**一句话**：功率循环 ton<5s 走键合线/金属化退化，ton>15s 走焊点开裂——两者寿命模型、判据、失效分析路径全不同。

**证据**：
- **一手**：AQG 324 附录 II.D（经 `04-canon.md` 提取）给出 LESIT 模型 `Nf = A·f^a·ΔTj^b2·exp(Ea/(k_B·Tj,mean))` 与 Bayerer 全参数扩展式
- **一手**：AQG 324 区分 PCsec（ton<5s）与 PCmin（ton>15s），并用 Rainflow 寿命消耗累加法
- **二手**：PCsec/PCmin 判据 5%/20% 源自工程共识，热阻测量重复性存在已知质疑（`03-workflows.md` §0-4）

**应用方式**：选 PC 条件前先确定要考核哪个失效机理，再定 ton/ton 区间。短 ton 考键合，长 ton 考焊点。

**局限**：SiC 模块的高 dv/dt 与高温门槛会改变主导机理；AQG 324 04.1 新增 Annex SiC 与 QL-08~QL-11 正是为此。

### MM-5｜跨体系编号映射比单体系知识更有价值

**一句话**：MIL-STD-883 的 1xxx 系列与 JESD22 的 A 系列几乎一一对应，会映射的人能跨三套体系定位。

**证据**：
- **一手**：MIL-STD-883F 原文目录 + 映射交叉（1010 温循↔A104、1011 热冲击↔A106、1005 稳态寿命↔A108、1014 密封↔A109）（`06-glossary.md` §0-3）
- **一手**：JESD22-A104F.01 参考文献直接引用 IPC-SM-785、JEP140、JEP153（`06-glossary.md` §C4）

**应用方式**：拿到一个不认识的编号，先判断它属于哪个体系的哪一段（见 §4 编号解码器），再走对应映射。

**局限**：映射不是等价——MIL-STD-883 的 1005 与 A108 版本不同、判据不同，仅作定位用。

## 2. 标准 Playbook（决策启发式）

> 表述为「如果 {场景}，则 {决策}」。

| # | 如果… | 则… | 依据 |
|---|---|---|---|
| PB-1 | 要做**车规**功率模块验证 | 走 **AQG 324**（不是 JESD47——后者 Scope 明确排除 under-the-hood） | 一手 JESD47 Scope |
| PB-2 | 客户 TS 与通用标准都有要求 | **取严**，并在报告中附「差异表」列出各自要求与选择理由 | `03-workflows.md` §4.2 |
| PB-3 | 机理涉及**水汽 + 电场** | 优先 **H3TRB**（不是 HAST）——IEC 60749-4 原文"THB 结果优先于 HAST" | 一手 IEC 60749-4 |
| PB-4 | 标准方法**不给循环次数**（如 A104） | 必须自己算：ΔTj 修正 → 寿命模型 → AF → N_test，绝不照抄 | 一手 A104F.01 §5 |
| PB-5 | 封装含 **Pb/Sn 焊料** | A104 中 Ts(max) > 125 °C 的条件**全部不可用**（CAUTION 4） | 一手 A104F.01 |
| PB-6 | 封装含**环氧塑封料**且 Ts(max) 接近 Tg | 先做 **DSC/TMA 测 Tg**；无 Tg 数据则该条件不可用 | 一手 A104F.01 CAUTION 1 |
| PB-7 | 试验数据**全数零失效** | 改用卡 chi方上界报告；**禁止**写"预计寿命" | MM-2 |
| PB-8 | 焊点失效评估 | 循环速率 ≤ 15 °C/min（优选 10–14）；大热质量功率模块需**单区箱体** | 一手 A104 |
| PB-9 | 要做**加速外推** | Ea 必须用**自有数据拟合**（JEP122/JESD91），二手文献的 Ea 值只能做量级参考 | 一手 JEP122 |
| PB-10 | 客户给的企业标准（LV324/VW80000 等）不可获得 | 从其**引用列表反推**关注点；引用了 AQG 324 就意味着要车规矩阵 | `05-sources.md` |
| PB-11 | 要判**标准现行性** | JEDEC 用 Reaffirmed / Superseded / Rescinded（**没有** Active/Withdrawn）；查 JM21W §7.2 的 5 年复审规则 | 一手 JEDEC |
| PB-12 | 输入编号是 **3 位**（如 "MIL-STD-883 M-101"） | 判定编号错误——MIL-STD-883 方法号是**4 位**（1001–1034/2001–2035/3xxx/5xxx） | 一手 MIL-STD-883F |

## 4. 编号解码器（从编号反查的规则层）

> 这是「从标准编号反查内容」的第一层能力：**看到编号就能判断体系、类型、年代、状态**。

### 4.1 体系判定（先判体系，再查表）

| 编号形态 | 体系 | 段含义 | 例 |
|---|---|---|---|
| `JESD22-{A\|B\|C}\d+` | JEDEC | 方法系列字母 + 方法号 | JESD22-A104 |
| `JESD\d+(-x)?` | JEDEC | 顶级标准 | JESD47 / JESD204 |
| `JEP\d+` / `JS-\d{3}` | JEDEC | 实践说明 / 联合标准 | JEP122 / JS-001 |
| `MIL-STD-883 Method \d{4}` | 军标 | 微电路方法（4 位） | Method 1010 |
| `SEMI [A-Z]+\d+` | SEMI | 系列字母 + 序号 | SEMI M1 / M40 |
| `IEC \d{5}-\d+` | IEC | 部分号 | IEC 60749-11 |
| `IPC-(TM\|A)\d+` | IPC | 试验方法/要求 | IPC-TM-650 / IPC-A-610 |
| `AEC-Q\d{3}` | AEC | 车规资格 | AEC-Q101 |
| `AQG \d{3}` | ECPE | 汽车资格指南 | AQG 324 |
| `(LV|VW|GMW|USCAR)\d+` | 车企 | 企业规范 | LV 324 |

### 4.2 段语义（以 JESD 为例）

```
JESD 22 - A 104 F .01
│    │   │ │   │ └── 增补号（.01/.02，⚠️ 不是年份）
│    │   │ │   └──── 版本字母（A..G，G=2022）
│    │   │ └──────── 方法号
│    │   └────────── 组别：A=环境/寿命  B=机械/几何  C=电/ESD
│    └────────────── 22 = 方法系列（JESD22 是方法库）
└─────────────────── 顶级 JEDEC 标准族
```

- **对比**：`JS-001-2017` 中 `2017` 才是年份；`JESD78F.02` 中 `F`=版本、`02`=增补。**两种结构必须区分**。

### 4.3 硬编码断言（已核实，可直接断言）

| 断言 | 内容 |
|---|---|
| A1 | `JESD22-A108` = **Temperature, Bias, and Life Test (TBL)**，全称无 "Voltage" |
| A2 | `JESD78` = **IC Latch-Up Test**（闩锁），**与 ESD 无关** |
| A3 | `JESD79-4` = **DDR4 SDRAM**；`JESD204` = **SerDes 接口** |
| A4 | `JESD22-A121` = **锡须生长测试**，非 ESD |
| A5 | `MIL-STD-883` 方法号是 **4 位**；1xxx↔JESD22-A、2xxx↔JESD22-B、3xxx 电气、5xxx 工艺 |
| A6 | ESD 三件套 = `JS-001`(HBM) + `JS-002`(CDM) + `A115`(MM, inactive)；A114/C101 已废止/撤销 |
| A7 | `JESD22-A112` → `J-STD-020`；`B102` → `J-STD-002D`；`B104` → `B110` |
| A8 | **AQG 324 对 UNECE R10 / ELV / RoHS / WEEE 零引用**（04.1/2025 全文检索证实）；其引用结构 = IEC 67% + JEDEC 10% + JEDEC JEP 24% |
| A9 | AQG 324 现由 **ECPE** 持有（非 ZVEI）；04.1/2025 为现行版 |
| A10 | `JESD22-A104F.01` **不规定循环次数**（由 JESD47 或双方约定）；中断 >总次数 10% 必须从头重启 |

### 4.4 拦截规则（CLI 必须内建）

1. **版本号必须保留**：`A104` ≠ `A104F.01`，输出须回显完整编号
2. **失效编号拦截**：命中 A112/A114/B102/B104/C100/C101/A115/JESD29/JESD34 → 先提示状态 + 替代编号
3. **3 位 MIL 方法号** → 判编号错误
4. **JESD204 被当 DDR4** → 主动纠正
5. **以"ESD 体系"名义查 JESD78** → 主动纠正为闩锁
6. **未核实条目**（见 §6）→ 返回 `⚠️未核实，需人工确认`，**禁止返回标题**

## 5. 引用关系建模

### 5.1 两种引用类型（必须区分）

| 类型 | 含义 | 提取方法 |
|---|---|---|
| **Normative（规范性引用）** | 构成本标准要求，**必须遵守** | 从标准正文 "Normative references" 表提取 |
| **Informative（资料性引用）** | 仅供参考，**无强制力** | 从 "Bibliography/References" 提取 |

### 5.2 引用数据源的现实约束（重要）

- **IEC Webstore** 产品页实测只有 `Product detail` / `Lifecycle` / `Normative references` 三个内容 Tab，**不存在 `Referenced by`**（`02-tools.md` 纠正）
  → 引用图谱只能从**各标准自身的 references 表反向抽取**
- **JEDEC 官网禁止自动化抓取**（服务条款 + curl 实测 403），且 ballot 全在 `vote.jedec.org` 内部，不公开
  → JEDEC 侧引用关系只能**人工核对** + 从已获取的 PDF 抽取
- **IEC stability date**（下次强制复审时点，**非最后更新日期**）可作换版预警信号
- **厂商报告只能证明"标准被采用"，不能证明"标准内容"**——两类断言必须分开建模

### 5.3 引用图谱的数据模型

```json
// edge 表：(src, dst, kind, clause)
{"src": "AQG324", "dst": "IEC60749-11", "kind": "normative", "clause": "3.2"}
{"src": "JESD22-A104", "dst": "IPC-SM-785", "kind": "normative", "clause": "References"}
{"src": "JESD22-A104", "dst": "JEP140",  "kind": "normative", "clause": "References"}
```

**查询语义**：
- `refs <STD>` → 该标准引用了谁（上游依赖）
- `cited-by <STD>` → 谁引用了它（下游影响面）— ⚠️ 受 §5.2 限制，JEDEC 侧不完整

## 6. 诚实边界（必读）

### 6.1 未核实项（CLI 禁止返回断言）

### 6.2 结构性局限

1. **信息截止 2026-10-05**。标准改版频繁（JESD22 每年升版、AQG 324 已到 04.1），**工具与数值条件模块衰减最快**，3–6 个月需复核。
2. **付费墙是硬约束**。IEC 正文 CHF 260（60749 有 42 parts）、JEDEC 全文 $284、SEMI $148–370 —— 本 skill 的一手内容来自免费可得部分。
3. **企业标准几乎不可公开获得**（LV324 / VW80000 / GMW / USCAR），设备厂规格书锁在 NDA 内。
4. **加速模型数值参数（Ea / b / h / n）全部来自二手**。应用前**必须用自有数据标定**；JEP122/JESD91 给方法，AE35 之类厂内数据库给值。
5. **本 skill 不能替代实操经验与标准原文**。所有引用条款号均为定位用，**判定必须回到标准原文**。
6. **公开信息有系统偏差**：成功者发声多、失败者沉默；厂商发布的选择性披露。
7. **JESD 侧引用图谱不完整**（禁爬），只有 IEC 侧可程序化抽取。

## 7. 智识谱系

| 流派 | 主张 | 代表 | 与本 skill 的关系 |
|---|---|---|---|
| **应力驱动派**（Stress-Test-Driven） | 用标准应力组矩阵证明可靠性 | JESD47 / JEP143 | 主流工程范式；汽车/军品基线 |
| **物理失效派**（Physics-of-Failure, PoF） | 用失效机理 + 模型外推，不做过度应力 | JEP122 / JEP148 / JESD94 | 抗辩"应力不真实"；McPherson 是 TDDB 权威裁判 |
| **知识驱动派**（Knowledge-Based） | 从使用条件+任务谱推导试验，不照抄固定应力 | **JESD94**（「标准条款→试验方案」的官方骨架） | 用户最该用的方法论层 |
| **统计零失效批判派** | test-to-pass 在数学上不可行（23 万样本） | IEC 60749-34:2025 / AQG 324 的 test-to-fail 转向 | 直接影响用户的 HV-H3TRB 结论写法 |

**核心分歧**：应力驱动派认为固定应力组可比较、可审计；物理失效派认为过度应力产生非现场失效（呼应 A104 的 Tg/Pb-Sn CAUTION）。**实务解法** = 用 JESD94 做知识驱动骨架 + 用 PoF 做机理论证 + 用应力驱动做最终判定。

## 8. Agentic Protocol（拿到新问题时的标准研究维度）

> 面对一个半导体标准问题，按这 7 个维度做功课后再回答。

| # | 维度 | 具体动作 |
|---|---|---|
| 1 | **体系定位** | 编号属于哪个组织/哪一段？（JEDEC 方法库 / JEDEC 资格标准 / SEMI 材料设备 / IEC / 车企企业规范） |
| 2 | **状态校验** | 现行？Reaffirmed / Superseded / Rescinded / 已废止？有无替代编号？ |
| 3 | **方法 vs 裁判** | 我要的是"怎么做"（JESD22）还是"做多少、判什么"（JESD47/JESD94/AQG 324/客户 TS）？ |
| 4 | **失效机理对齐** | 目标失效模式是热-机械/热-电/湿热/电应力哪一类？该机理的原生试验是哪个？ |
| 5 | **产品适配修正** | 标准条件是否越过我的 Tg / Pb-Sn 限制 / ΔTj 实际值 / 循环速率 / 腔体均匀性？ |
| 6 | **引用链追溯** | 该标准引用了谁（normative vs informative）？上游变更如何影响我？客户 TS 引用的底层标准是什么？ |
| 7 | **统计与判据** | 样本量够吗？零失效怎么报？判据是标准给的、采购文件给的、还是自定义的？ |

**输出纪律**：凡涉及具体数值条件（温度/时长/循环次数/ΔTj/样本量），必须先说明来源层级（标准原文 / 二手 / 未核实），未核实项显式标注。

## 9. 关键公式索引

| 公式 | 用途 | 变量 | 出处 |
|---|---|---|---|
| 卡方零失效上界 `R_L = 1 − χ²₍₁₋CL₎/2S` | 零失效数据的失效率上界 | CL=置信度，S=Σ(n_i×t_i) | 通用统计 |
| Arrhenius `AF = exp(Ea/k · (1/T_use − 1/T_test))` | 温度加速因子 | Ea[eV]，k=8.617×10⁻⁵ eV/K | JEP122 |
| Coffin-Manson 幂律 `AF = (ΔT_test/ΔT_use)^B` | 焊点热疲劳 | B=耗损指数 | 通用 |
| **Norris-Landzberg** `N_L/N_M = (f_L/f_M)^(1/3)·(ΔT_M/ΔT_L)²·Φ(T_max)` | 焊点疲劳（含频率与最高温修正） | Φ=Arrhenius 修正 | IPC-SM-785 / A104 体系 |
| **LESIT 功率循环** `Nf = A·f^a·ΔTj^b2·exp(Ea/(k_B·Tj,mean))` | 功率模块焊点/键合疲劳 | Tj,mean=平均结温 | AQG 324 附录 II.D |
| **Bayerer 全参数扩展式** | 功率循环（含材料/几何项） | 多参数 | AQG 324 附录 II.D |
| Peck 湿热 power law | 铝腐蚀 | 85/85 基准 | JESD22-A101 理论基础 |
| Rainflow 寿命消耗累加 | 变温工况下的损伤累积 | — | AQG 324 |

> ⚠️ 所有 Ea/B/b/n **数值**均为二手，应用前须用自有数据（JEP122/JESD91 方法）标定。
